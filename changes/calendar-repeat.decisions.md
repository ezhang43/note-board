- 2026-11-23 Calendar repeat options (owner request, 2026-11-22; worker calls, rule 4 exception): the Repeat dropdown shows in both quick-add and the full form (matching Google Calendar's quick-add) so recurring events don't require an extra click into More options. Days 29–31 use `-1` ("last weekday") for "Monthly on the last \<weekday\>" so the series fires every month rather than skipping shorter months. Timed `UNTIL` values convert local 23:59:59 to UTC (`YYYYMMDDTHHMMSSZ`) per RFC 5545 while all-day events use `YYYYMMDD`, so end dates round-trip in every time zone. Changing the repeat on an existing repeating event requires keeping the same day and all-day setting (since moving a day or toggling all-day applies only to one instance), and Save's "which events?" dialog explains "Changing how it repeats updates all events in the series." with Cancel and All events in the series. Unsupported RRULEs (multiple rules, `EXDATE`/`RDATE`, `BYSETPOS`, non-matching `BYMONTHDAY`/`BYDAY`, or multi-week non-Sunday `WKST`) show as read-only "Custom repeat (edit in Google Calendar)" and are omitted from PATCH so they are never overwritten. The pure RRULE model and occurrence expander live in `src/model/calendarRepeat.ts`.
