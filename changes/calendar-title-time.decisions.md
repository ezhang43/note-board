- 2026-11-22 Calendar time in the title (job calendar-title-time; coordinator's recommended calls, rule 4 exception): an all-day event is left alone (it has no start time); only the first time found counts, later ones stay as words; the title is tidied (doubled spaces collapsed, ends trimmed); a title that is only a time saves empty and shows as "(No title)"; a repeating event's "which events?" and guest-email questions work as before, with the new times; a range whose end is at or before its start ignores its end and keeps the length; Undo and Ctrl+Z restore the old title and time like any save.
- 2026-11-22 Calendar time in the title (worker calls, recommended options): "8p" needs no space, but a single letter after a space ("2 a day", "8 p") is not read as a time, so "Run 5 a day" stays as words ("8 pm" and "8 p.m." still count). A range with no am / pm on its start takes its end's ("8-9pm" is 8pm), or am when that would put the start at or after the end ("11-1pm" is 11am to 1pm). A range on an event over several days ends on its first day. A range whose end can't be read ("8pm-9") counts only its start and leaves "-9" in the title. The title is read only when it was changed in this form (always for a new event), so an existing event whose name already holds a time ("Standup 9am", perhaps named in Google Calendar) is never moved by a Save that changes something else, and a start picked in the time box then wins (code review finding). The form keeps what was typed, not the tidied title, so Cancel on a question and Save again gives the same result rather than reading the next time in the name. Brackets left empty and a separator left at either end (, ; : @ - – —) are removed too ("Dinner (8pm)", "Dinner - 8pm" save as "Dinner"). Ranges written with "to" ("8 to 9pm") are not read as ranges (not in the owner's list), and a range past midnight ("11pm-1am") keeps the length as the coordinator's call says. Dragging an event to another day does not read its title (only the form's Save does). The parsing is `titleTime` in `src/model/calendarTitleTime.ts`.
