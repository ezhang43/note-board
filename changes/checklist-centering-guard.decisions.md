- 2026-10-23 The centering rule (box 5% of the line height below the middle of the item's first line; gap 6px times the item buttons' step; box 20px times the step, 16px on a phone) is now written in SPEC.md and measured by `e2e/checklist-centering.spec.ts`. Why: owner request, "the centering of the text for checklists gets moved ... ensure that this stays consistent".
- 2026-10-23 The test allows half a pixel, not the 1px first asked for: the nudge is only 1px at Normal, so a 1px tolerance would let a 1px slip there pass. The test finds which line the first character is in with a text range, then uses that line box's exact middle, because a text range's own box is rounded to whole pixels by the browser (it differed by up to 1px from the line box with exact CSS).
