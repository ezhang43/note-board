- 2026-11-11 Content Security Policy (job 11): a `<meta http-equiv>` tag on all six built pages, made by `scripts/csp.ts`, since GitHub Pages can't send headers. `frame-ancestors`, `report-uri` and `sandbox` are left out (browsers ignore them in a meta tag). Why: the plan's job 11, before the feature that keeps the person's own Anthropic key in the browser.
- 2026-11-11 CSP: Firebase popup sign-in needs `script-src https://apis.google.com` and `frame-src https://note-board-a672a.firebaseapp.com`. Source: the installed `@firebase/auth` (firebase 12.19.0): `gapiScript: 'https://apis.google.com/js/api.js'`, `loadGapi` and `getIframeUrl` (`https://<authDomain>/__/auth/iframe`); a browser test confirms clicking Sign in loads api.js under the policy. The whole `apis.google.com` host is allowed because api.js loads its iframe module from `apis.google.com/_/scs/...`. Firebase's and Google's documentation pages couldn't be reached from the build session, so the lines rest on the SDK's code and Google's GIS script, not the docs.
