- 2026-10-23 Dragging a checklist item: the whole box of an open checklist (empty space under the items, the title row, the card's padding, the card dragged from) takes the item at the end of that list, the same card's own empty space included. Item rows keep before / after / nested. Why: that is what the owner asked for, and it is the same drop a collapsed list already took.
- 2026-10-23 Unchanged on purpose: items dropped on a note, link or other kind of card, on an open container's empty space, or on a collapsed container still make a new list (SPEC "Dragging items"); only checklists take items. A checklist inside a container takes items the same way as a loose one. The phone's press-and-hold lift uses the same drop code as the grip, so it behaves the same.
