- 2026-10-29 Tick box tap on an iPhone (job 224; worker calls): emulated WebKit sent no click after a touch tap whose pointerdown was cancelled (the cancel that keeps the focus in the text, job 218), so the box never ticked. A finger tap that keeps the focus now ticks the box itself on the touchend, and cancels that touchend so the browser's own click (and its focus change) never follows, in every browser, so there is no second tick. A finger that slides off the box before lifting ticks nothing. A pen in a browser without touch events still goes through the click as before.
