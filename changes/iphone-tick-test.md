## Automatic iPhone check for the tick box tap (2026-10-29)

- No change to the app. The browser tests now also run the "tap a tick box while typing keeps the cursor and the keyboard in the text" checks in Safari's engine (WebKit) on an iPhone 14 profile, so this no longer needs a real iPhone. It is an emulation: it checks where the cursor stays, not how a real iPhone keyboard looks or feels.
