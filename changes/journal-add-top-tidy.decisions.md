- 2026-11-11 Journal general notes, the old "add after this note" check: before the + moved to the top, adding a note refused when the note id passed in wasn't a general note. The add no longer takes an "insert after this note" id (a new note always goes first), so there is nothing to refuse and that check was not brought back. The id `addJournalNote` still takes only names the first note (the id "General notes" is created under when none is written) and the card the new one is placed below. A stale or unknown id passed to the add now only changes where the card sits on the Journal board (it falls back to the spot beside everything), never the list, so it can't hide or drop written notes; a new test (`+ given an id that is not a note…`) covers it. A mutation that lets the "General notes" note be added twice makes that test fail.
- 2026-11-11 Journal general notes, the default for typing: the store's `setJournalNotes` without a note id writes into the first note in the list. Since new notes go on top, that is now the newest "Untitled note" rather than "General notes". The panel always names the note, so no button or key relies on the default; it is kept as it is, documented in the code and pinned by a test.
