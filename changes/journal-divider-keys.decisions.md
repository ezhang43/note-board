- 2026-11-11 Journal divider keys (owner request, "change it to be -- instead of ---", "alt + I + R like Google Docs"): only the typing trigger changes. A divider's plain text stays the line `---`, so the board card, search, Download as text, copying and the Claude connector are unchanged, and there is no save-format change (call, from the coordinator).
- 2026-11-11 `---` + Enter no longer makes a divider, and neither does Enter at the end of an old plain `---` line (call). A typed `---` and an old plain `---` line are the same saved line, so the old rule could not be kept without keeping the typed one; it was dropped. Old `---` lines stay words, nothing is lost.
- 2026-11-11 Alt+I, then R (call, from the coordinator): a sequence, not a chord. R must come within 1.5 seconds, Alt held or released; any other key cancels it, pressing a modifier does not. Matched on the key's place (KeyI, KeyR), never the character, so other layouts and a Mac (Option+I is a dead key) work; both keys are stopped. It only acts inside a Journal note, never on the board behind. It does what the Divider button does, as one Ctrl+Z step. Listed in the Keyboard shortcuts panel and the Divider button's tooltip.
