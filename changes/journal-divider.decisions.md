- 2026-10-31 Journal divider (owner decision, "Button + type ---"): a thin gray line across the note from the Divider button in the Formatting bar or from `---` + Enter on an empty line. Backspace or Delete next to it removes it, and Ctrl+Z undoes that. It is saved, synced, kept in Version history and read by the connector. Plain-text and markdown exports show it as `---`.
- 2026-10-31 Divider, how it is saved (call, recommended): a formatting line of type `hr` whose words are `---`. The note's plain text keeps the line `---`, so the board card, search, Download as text, Version history previews and the connector (which reads the plain text) need no new code. No new save version (it stays 4). An older copy of the app reads an unknown line type as a plain line and keeps its words and the rest of the note's formatting, so an old tab shows the words `---`. If that tab saves, the divider stays those words; nothing else is lost. A version bump would instead have made old tabs show "Your board couldn't be loaded" (as version 4 did). The saved-shape guard test (`persist-roundtrip.test.ts`) lists `hr` as a value older copies read safely, so any other new value still needs a version bump.
- 2026-10-31 Divider: a Claude connector installed before this change refuses to edit a board that holds a divider ("data this connector doesn't know"), because its round-trip check sees the new line type. Nothing is changed or lost. It works again once the connector is updated.
- 2026-10-31 Divider button placement (call, recommended): it goes after the current line. On an empty line, that line becomes the divider. A selection is replaced. The cursor never rests on a divider: typing, Enter, Style and the list buttons skip it.
- 2026-10-31 `---` + Enter only converts a plain line, not a heading or a list item (call, recommended). In those, `---` is likely meant as words.
- 2026-10-31 Backspace on a list item right after a divider outdents the item first, as Backspace at the start of an item always does. It removes the divider only once the line is plain (call, recommended).
- 2026-10-31 Dividers are not counted in the Journal's word count. A plain `---` line written before is not counted either (call, recommended).
- 2026-10-31 Download as text writes a divider as a raw `---` line, as the owner asked. In Markdown viewers, a line directly above it can show as a heading (Markdown's own rule). Left alone, because a plain `---` line in a note already exported that way.
- 2026-10-31 Divider, after the high review: Enter at the end of a plain `---` line written before the divider existed also makes it a divider (call, recommended). That line looks exactly as if it had just been typed, and the owner's rule is "`---` on an empty line, then Enter". Opening the note never changes it. Ctrl+Z puts it back as words.
- 2026-10-31 Divider: Backspace right after pressing Divider removes the line but leaves the new empty line below it, like deleting one character (call, recommended). Ctrl+Z undoes the whole button press in one step. A folded day's first line skips a divider.
