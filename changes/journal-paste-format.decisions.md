- 2026-11-01 (owner request: pasting into the Journal should keep the copied text size and the indents of a list; the owner's answers were relayed by the crew coordinator; the calls below were made by the worker under rule 4's exception). (1) The app's own copies are recognized by a hidden clipboard type written during the copy event (`application/x-note-board-journal` for Journal lines; the existing `application/x-note-board-items` for checklist items, whose value is now the items as JSON instead of `1`). The formatted content travels as JSON in the type's value, so it also works across browser tabs; it is read back with `parseRich` / a checked reader, and anything damaged, or the old value `1`, means no marker, so the plain text is pasted. The plain-text clipboard is unchanged. Nothing new is saved (the Journal stays at version 4). (2) Ticked checklist items pasted into the Journal arrive as plain words with no tick (the recommendation; the Journal has no ticks). (3) Headings pasted into a checklist become bold items, Heading 1 also Large; blank lines and dividers are skipped. (4) Item sizes map to Journal sizes Small = 14 px and Large = 20 px (both in the size box's list), and back: under 16 px is Small, over 16 px is Large. (5) A Journal line's looks become the item's look only when every letter of the line has them; underline, strikethrough and highlight are dropped in a checklist, which has none. (6) A copy's first line stays a list item or heading only when the selection starts at the start of that line; otherwise it is plain words, as Google Docs does. (7) Several pasted lines join the first to the words before the cursor and the last to the words after it, as Google Docs does; a divider is never pasted into, it goes beside the line. (8) Journal lines paste into a checklist only while typing in an item (as #228 does for items); with items highlighted, Ctrl+V keeps using the in-app item copy. (9) A rich paste is one Ctrl+Z step of its own (like a formatting change); typed text and plain pastes merge into typing steps as before. (10) Items copied across several lists still carry no marker (as in #228). Items pasted from checklist to checklist still use this tab's own copy; only the Journal paste reads the JSON, so it works from another tab.
