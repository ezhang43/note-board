Words after the cursor stay as the item's words. Ctrl+Z right after brings back the typed "1. " as words, with the cursor after them.
- 2026-11-21 Typed lists (worker call): `- ` and `* ` at the start of a plain line start a bulleted list the same way, since the owner expects bullets to work like this.
- 2026-11-21 Numbering (worker calls): levels go 1. a. i. and repeat from the fourth level, as in Google Docs. Letters continue past z as aa, ab, …. The Numbered list button and Ctrl+Shift+7 make the 1. style; a numbered item made numbered again keeps its style. Items of both styles in one run count on together (no restart when the style changes).
- 2026-11-21 Saving (worker's recommended call, put to the owner in the pull request): the 1) style is saved as `paren: true` on the numbered item, with no new format version (it stays 6). An older copy of the app leaves it out, so it shows that note as its plain text with every word kept; if that copy saves the note, only that note's formatting is lost. The same is true for deeper numbered levels written now, because their text has "a.". The alternative is raising the version to 7, so older copies refuse the boards until reloaded and older connectors only read until reinstalled.
- 2026-11-21 Notes saved before the letters (worker call): a note whose text still says 1. 2. at the deeper levels keeps its formatting (it is matched against the old numbering too) and is shown with letters. Its text is rewritten with the letters only at its next edit, so nothing saved changes when it is opened.
