- 2026-10-22 (owner request, job 188: "instead of the hand or select option, make it so that it is naturally on the select option, but make it so that holding down both left and right click or holding down the middle click can drag the board around"; recommended options, rule 4 exception). (1) **Tools removed:** `View.tool`, `setTool`, the Hand / Select buttons and tiles, their two keys (`hand`, `select` in `HOTKEY_NAMES`; five re-mappable keys remain) and the `tool-*` canvas class are deleted. A saved view or hotkey set that still names them loads fine (unknown fields are ignored). (2) **Mouse pan** is one window-level hook, `src/components/usePanButtons.ts`: middle button, or left+right in either order, detected from the pointer and mouse events' `buttons` bits; it stops the press reaching cards, cancels a begun left drag with a `pointercancel`, refuses the click, context menu and middle-click new tab it would cause, and ends on releasing a button, blur or a cancelled press. Not available while an old version is shown or a panel covers the board. (3) **Cursor:** a closed glove while panning, over everything on the board (`.canvas.panning *`), else the normal arrow; the open glove is gone. (4) **Touch:** one finger swiping on empty board still pans (unchanged); because the Select tool can no longer be picked on a phone, a finger that rests about half a second and then moves now draws the selection box (like resting then moving picks up a card), so selecting several blocks by finger and moving them together still works. Owner may prefer another way. (5) **Added a row to the shortcuts list** ("Middle button, or left + right buttons together") so the hidden gesture can be found, since the Hand button was its only visible cue. (6) **Limit kept:** on macOS and Linux the browser opens the context menu when the right button goes down, so pressing right first can show it before the left joins; Windows (menu on release) and left-first are clean. (7) The Board group in the phone ⋯ sheet keeps A− / A+ alone on a row, as two even halves.
