- 2026-10-23 A list made from dragged-out items copies the source list's own width (`w`) only when the source is loose on the board. A source inside a container, or at the default width, gives the default width (`w: null`). Why: a container's lists have no width of their own (the container sets it), and the code has no clean way to read a rendered width in the model; copying a stale saved width would be wrong. Upgrade if the owner wants a container's width carried over.
- 2026-10-23 A new list made at the end of a container always has `w: null`, so a later drag out of the container does not bring back an old width. Dropping items onto an existing list never changes that list's width.
