- 2026-11-11 (call, recommended) While this person's own leave of a shared board is on its way, the server saying they are off it is that same leave: no second leave is sent and no "no longer shared with you" note shows. "Was deleted by the person who shared it" still shows if the owner deletes it meanwhile. A list of their shared boards that still names a board they just left (sent before the leave) doesn't open it again; once a list no longer names it, or they open its link again, it is treated as usual (so being added back on another device still brings it here). Why: a flaky browser test showed join, leave, leave; this is the smallest fix that keeps every note the spec promises.
- 2026-11-11 (call, recommended) If the leave itself then reports an error but the server has already said they are off the board (so it has gone from this page), the Share panel doesn't show "That didn't work": the leave did take effect. Why: the spec's "if it doesn't work, nothing changes" can't hold once the board is gone, and showing an error for a board that left would confuse.
