## Leaving a shared board sends one leave (2026-11-11)

- Opening a link to a shared board that can't be used, or leaving a board someone shared with you, now tells the server once that you are leaving. Before, if the server said "you're off this board" before it had answered the leave itself, the app sent a second leave, and leaving from the Share panel could also show "no longer shared with you". An out-of-date list of your shared boards no longer opens a board you just left, either. Nothing else you see changes. If leaving doesn't work ("That didn't work"), the board now always stays open as before, even when the server's list of your shared boards already left it out. After you are removed from a board, an out-of-date list no longer shows "no longer shared with you" a second time.
