- 2026-10-29 Delete in a ticked checklist item (owner report, job 218; coordinator's calls): with the cursor anywhere in a ticked item's text and nothing selected, Delete removes the item and everything nested under it, exactly as its trash can (same function, one undo step), instead of deleting a letter or joining the item below. The cursor goes where the phone's trash leaves it: the item above, else the one below. Ticked text is editable, so Backspace keeps editing it. Open items are unchanged; Delete at the end of an open item still joins a ticked item below it.
- 2026-10-29 Root cause of the card being deleted: clicking a tick box leaves the keyboard on the box (a checkbox, not a text field), so the board's "not while typing" check let Delete / Backspace through to "delete the selected card". Fixed at the board's delete key: when the focus is anywhere inside a checklist item row (tick box, trash, arrows), Delete / Backspace (or the person's own Delete key) remove that item, open or ticked, never the card.
- 2026-10-29 With letters of a ticked item selected, Delete deletes just those letters, and Shift/Ctrl/Alt/⌘+Delete are left to the text (worker calls: a selection or a modifier shows the person means the text). Only a fresh press removes an item: after Delete or Backspace removed one, the held key's repeats do nothing in the item the cursor moved to, until the key is pressed again, so it can't remove or join more items (worker call after the high review).

With the focus on a tick box, the board's own Delete key, if the person changed it, removes the item too. If other blocks are selected as well (Ctrl+A with the focus on a box), Delete deletes the selection as before (worker calls after the high review).

- 2026-10-29 Tapping a tick box on a touch screen (finger or pen) leaves the focus where it was, so an iPhone's or Android phone's keyboard stays up while typing in an item (owner: "fix iPhone first", job 218 round 2). Only a mouse or trackpad click gives the box the keyboard, with `focus({ focusVisible: false })` (Chrome 145, Firefox 104, Safari 18.4; older browsers ignore the option and already hide the ring after a click, since the tick box ring is `:focus-visible` only). On Android Chrome this also stops the tapped box taking the focus, which it did before this change (worker call: the same rule on every phone).
